# VIZIO AI — Design Guidelines

## 1. Estilo Visual
Clean, Moderno, Alto Contraste. Referências: Linear, Vercel.

## 2. Paleta de Cores
* **Primary:** #22C55E (Verde Acessibilidade)
* **Background:** #FFFFFF (Branco Puro)
* **Focus:** #3B82F6 (Azul de Destaque)

## 3. Tipografia
Inter ou System Sans-serif. 
* Corpo: min 16px.
* Títulos: min 24px.

## 4. Componentes (shadcn/ui)
* **Badge:** Para estados (LISTENING, PROCESSING).
* **Progress:** Barra de progresso no topo da página.
* **Toast:** Notificações de erro ou sucesso.
